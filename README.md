# FreeHost – MTA:SA Panel (UI Starter)

واجهة عربية RTL أولية للوحة تحكم FreeHost الخاصة بـ MTA:SA.

## التشغيل
افتح `index.html` في المتصفح، أو ارفع الملفات إلى جذر مستودع GitHub Pages.

## الموجود حالياً
- لوحة جانبية: Overview, Console, Resources, File Manager, SFTP, ACL, Settings.
- بطاقات حالة السيرفر وIP واللاعبين وCPU وMemory.
- أزرار تشغيل/إيقاف تجريبية وسجل Console محلي.
- تصميم متجاوب للهاتف والكمبيوتر.

## مهم جداً
هذه **واجهة Frontend تجريبية فقط**. لا تشغّل MTA:SA فعلياً ولا تنشئ IP أو SFTP حقيقي، ولا تقيس CPU أو Memory. أزرار التشغيل والأوامر لا تتصل بسيرفر حقيقي.

لإضافة الاستضافة الحقيقية لاحقاً نحتاج:
1. خادماً Linux أو مزود استضافة يسمح بتشغيل MTA:SA.
2. Backend API آمن لإدارة عمليات السيرفر.
3. مصادقة وصلاحيات لكل مالك سيرفر.
4. مراقبة موارد النظام وقراءة حالة MTA.
5. خدمة ملفات آمنة (SFTP أو مدير ملفات مضبوط الصلاحيات).
6. جدار حماية وحدود موارد وعزل لكل سيرفر.

لا تضع كلمات مرور أو مفاتيح SFTP داخل ملفات الواجهة أو GitHub.
