# FreeHost Minecraft v2

واجهة أمامية تجريبية باللغة العربية وبدعم RTL.

## الملفات
- `index.html` واجهة تسجيل الدخول ولوحة التحكم.
- `style.css` التصميم.
- `app.js` التفاعلات التجريبية.

## التشغيل
افتح `index.html` في المتصفح أو ارفع الملفات إلى جذر مستودع GitHub Pages.

## تنبيه مهم
تسجيل الدخول هنا تجريبي فقط ولا ينشئ حسابات آمنة أو يخزنها في قاعدة بيانات. السيرفرات والكونسول وأزرار التشغيل والإيقاف محاكاة محلية، ولا يوجد اتصال فعلي بـ Minecraft. لا تضع كلمات مرور أو مفاتيح API أو بيانات استضافة في ملفات الواجهة العامة. يلزم Backend وقاعدة بيانات ومزوّد استضافة يدعم واجهة API قبل تشغيل سيرفرات حقيقية.
